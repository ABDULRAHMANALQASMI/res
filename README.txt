## ✨ Key Features
- **Responsive Web Layout:** Modern UI that adapts smoothly across desktops, tablets, and smartphones.
- **ATS-Compliant & Print-Ready:** Built-in PDF export styles that follow international A4 standard formatting for recruiters.
- **Clean Architecture:** Semantic HTML5 and modular CSS without external heavy framework dependencies.

## 📄 How to Export to PDF
1. Click the **"Print / Download PDF"** button at the top of the live page.
2. Set the destination to **"Save as PDF"**.
3. Ensure margins are set to **"Default"** or **"None"** and save.
